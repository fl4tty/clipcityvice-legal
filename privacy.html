Privacy Policy

Last updated October 31, 2026

This tool does not collect, store, sell, or share personal data belonging to anyone other than its operator, and does not serve any user other than its operator.

  • What is stored: an OAuth access token and refresh token issued by TikTok for the operator's own account, saved locally on the operator's own computer in a configuration file. These are used only to authorize video uploads to that same account.
  • What is not collected: no analytics, no third-party data sharing, no advertising identifiers, and no data about any TikTok viewer, follower, or other user.
  • Data retention: the stored tokens remain only on the operator's local machine and are deleted if the operator removes the local configuration file or revokes access via TikTok.
  • Contact: clipcityvice@gmail.com
